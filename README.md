# PRY2204 - Semana 7

## Descripción

Este repositorio contiene el desarrollo de la actividad de la Semana 7 del módulo PRY2204, utilizando Oracle SQL Developer.

El trabajo contempla la creación y modificación de un modelo relacional, el poblamiento de tablas y la realización de consultas SQL para la recuperación y simulación de información.

## Contenidos

- Creación de tablas y restricciones.
- Claves primarias, foráneas, únicas y restricciones CHECK.
- Creación y utilización de secuencias.
- Poblamiento de tablas.
- Consultas SQL.
- Simulación de renta promedio.
- Nueva simulación de renta con aumento adicional.

## Herramientas utilizadas

- Oracle SQL Developer
- Oracle Database
- SQL

## Archivo principal

`PRY2204_SEMANA7.sql`

Contiene el script SQL completo desarrollado para la actividad.
